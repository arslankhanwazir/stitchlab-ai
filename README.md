# StitchLab AI

Private document assistant for small agencies. Answers only from the client's documents, with citations, a "Not found in your documents" response, and two kinds of conflict detection.

**Demo:** Brightpath Media (demo) is a FICTIONAL sample agency. Every document, name, number, and contact in this repository is invented.

## Start here
1. `docs/project-record/` holds the milestone plan (File 1) and the project record (File 2). Follow these.
2. `documents/` holds the fictional Brightpath documents and the ten golden test questions.
3. Work one milestone at a time. Each milestone has a done-check. Record the result before starting the next.

## Rules
- No API keys, client documents, or personal data in this repository.
- Local model (Ollama) is the default. No paid API is used for the founder's demo.
- Label all demo content "Brightpath Media (demo), fictional."
